🚀 เริ่มต้นใช้งาน

ขั้นตอนการติดตั้ง

  1. โคลนที่เก็บ - คัดลอกโครงการจาก GitHub
  2. ติดตั้งการพึ่งพา - รัน pip install -r requirements.txt
  3. เริ่มเซิร์ฟเวอร์ - รัน python main.py
  4. เปิดเบราว์เซอร์ - ไปที่ http://localhost:3000
  5. เริ่มสร้าง - สร้างลูกค้าแรกของคุณ

โครงสร้างโครงการ

project/
├── src/
│ ├── main.py
│ ├── api.py
│ ├── database.py
│ └── agent.py
├── frontend/
│ ├── index.html
│ ├── styles.css
│ └── app.js
└── requirements.txt

📖 ข้อมูลอ้างอิง API

จุดสิ้นสุด API หลัก

GET /customers

ดึงรายการลูกค้าทั้งหมด

POST /customers

สร้างลูกค้าใหม่

GET /customers/{id}

ดึงข้อมูลลูกค้าตามรหัส

PUT /customers/{id}

อัปเดตข้อมูลลูกค้า

DELETE /customers/{id}

ลบลูกค้า

  "travel": false
}

🎓 บทช่วยสอน

🔧 บทช่วยสอนที่ 1: การตั้งค่าเบื้องต้น

เรียนรู้วิธีการติดตั้งและเปิดใช้งาน AI CRM Assistant เป็นครั้งแรก

  1. ดาวน์โหลดและติดตั้ง Python 3.11+
  2. โคลนที่เก็บโครงการ
  3. ติดตั้งการพึ่งพาที่จำเป็น
  4. เริ่มเซิร์ฟเวอร์ FastAPI
  5. ตรวจสอบว่าหน้าแรกทำงาน

👥 บทช่วยสอน 2: การจัดการลูกค้า

สร้าง อัปเดต และจัดการข้อมูลลูกค้าของคุณ

  1. สร้างลูกค้าใหม่ด้วยข้อมูลพื้นฐาน
  2. ค้นหาลูกค้าโดยใช้เกณฑ์ต่างๆ
  3. อัปเดตข้อมูลลูกค้าที่มีอยู่
  4. ลบลูกค้าที่ไม่ต้องการ
  5. ใช้ API เพื่อการบ่วงดำเนินการหลาย ๆ

🔗 บทช่วยสอน 3: การใช้ API

ประสบการณ์ในการเรียก API จาก JavaScript

  1. ทำความเข้าใจ REST API
  2. ใช้ Fetch API สำหรับการโทร
  3. จัดการ JSON และข้อมูลการตอบกลับ
  4. การจัดการข้อผิดพลาดและการยืนยัน
  5. การทดสอบ API ด้วย cURL หรือ Postman

🤖 บทช่วยสอน 4: การใช้คุณสมบัติ AI

ใช้ประโยชน์จากการวิเคราะห์และการทำนายที่ขับเคลื่อนด้วย AI

  1. ทำความเข้าใจ AI Agent Framework
  2. ดำเนินการวิเคราะห์ลูกค้า
  3. ใช้เครื่องมือการค้นหาโดยอัตโนมัติ
  4. รวมเข้าระบบ CRM ของคุณ
  5. อัตโนมัติของวิธีการทำงาน

⭐ เทคนิคที่ดีที่สุด

🔒 ความปลอดภัย

  • ตรวจสอบอินพุตทั้งหมดก่อนส่งไปยังเซิร์ฟเวอร์
  • ใช้ HTTPS เสมอในการผลิต
  • บันทึกสิ่งอื่น ๆ ทั้งหมด และตรวจสอบกิจกรรม
  • จำกัดสิทธิ์การเข้าถึง API

⚡ ประสิทธิภาพ

  • ใช้การแพตช์และการโหลดหลายเหตุการณ์เพื่อความมีประสิทธิภาพ
  • แคช ข้อมูลเมื่อเป็นไปได้
  • ตรวจสอบคำขอ API ด้วยหมายเลข
  • ใช้ดัชนีฐานข้อมูลสำหรับการค้นหา

🔧 การบำรุงรักษา

  • ใช้ Git สำหรับการควบคุมเวอร์ชัน
  • เขียนการทดสอบหน่วยสำหรับโค้ด
  • ทำเอกสารขอบเขต API และการใช้งาน
  • ตรวจสอบและชอบให้คนอื่นทำการตรวจสอบ

📊 การตรวจสอบ

  • บันทึกข้อมูลประเภทและปริมาณเพียงพอ
  • ตรวจสอบเมตริก API (เวลา การตอบสนอง ข้อผิดพลาด)
  • ตั้งค่าการแจ้งเตือนสำหรับข้อมูลอัตราการผิดพลาด
  • ทำการวิเคราะห์เป็นระยะเวลา

❓ คำถามที่พบบ่อย

ฉันจะเริ่มต้นกับ AI CRM Assistant ได้อย่างไร?

ทำตามส่วน "เริ่มต้นใช้งาน" ข้างต้น บทช่วยสอนตามขั้นตอนแสดงวิธีการติดตั้งและเพื่อเรียกใช้หลักการแรก

API ข้อมูลจำเป็นสำหรับการสร้างลูกค้าคืออะไร?

คุณต้องการ: ชื่อ อีเมล บริษัท การทำงาน (บูลีน) และการเดินทาง (บูลีน) โปรดดูส่วน "ข้อมูลอ้างอิง API" สำหรับตัวอย่างมากขึ้น

ฉันสามารถใช้ AI CRM Assistant กับฐานข้อมูลอื่นได้หรือไม่?

ใช่ คุณสามารถรวมฐานข้อมูล PostgreSQL, MySQL หรือ SQLite ได้ แก้ไขไฟล์ database.py เพื่อเปลี่ยนการเชื่อมต่อ

ฉันจะขึ้นเซิร์ฟเวอร์เพื่อใช้งานจริงได้อย่างไร?

สามารถขึ้น Docker บน AWS, Azure หรือ Heroku เราแนะนำให้ใช้ HTTPS เปิดใช้งาน CORS อย่างถูกต้อง และบันทึกทั้งหมดเพื่อการติดตามบ้าน

ฉันจะเพิ่มคุณสมบัติใหม่ได้อย่างไร?

เพิ่ม API endpoints ใหม่ใน api.py และติดตั้งวิธีฐานข้อมูลใน database.py จากนั้นเพิ่มฟอร์มฟ้อนท์เอนด์ใน HTML และดึง JavaScript

ฉันจะได้รับการสนับสนุนหรือความช่วยเหลือได้อย่างไร?

ติดต่อทีมการสนับสนุน ตรวจสอบเอกสารประกอบอย่างละเอียด เรียกดูปัญหา GitHub หรือเข้าร่วมชุมชนจำนวนมากของเรา
